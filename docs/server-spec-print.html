3.2 tc htb (Initial)

#!/bin/bash
# /opt/mira-vpn/tc-tiers.sh — idempotent, run at boot
IFACE=enp1s0 PORT=51820
tc qdisc del dev $IFACE root 2>/dev/null || true
tc qdisc add dev $IFACE root handle 1: htb default 99
tc class add dev $IFACE parent 1: classid 1:1 htb rate 1000mbit ceil 1000mbit
tc class add dev $IFACE parent 1:1 classid 1:99 htb rate 200mbit ceil 1000mbit   # system
tc class add dev $IFACE parent 1:1 classid 1:2  htb rate 800mbit ceil 800mbit    # vpn pool
tc class add dev $IFACE parent 1:2 classid 1:10 htb rate 5mbit ceil 5mbit         # paid per IP
tc class add dev $IFACE parent 1:2 classid 1:20 htb rate 500kbit ceil 500kbit     # free per IP
tc filter add dev $IFACE protocol ip parent 1:0 prio 99 u32 match ip sport $PORT 0xffff flowid 1:20

3.3 Per-IP MARK (Production)

# Inside tunnel-api.py add_peer():
def apply_mark(ip, tier):
    mark = "0x10" if tier == "paid" else "0x20"
    subprocess.run(["iptables","-t","mangle","-A","POSTROUTING","-s",ip,"-j","MARK","--set-mark",mark], check=True)

Then tc filters by mark: match mark 0x10 0xff → paid class, 0x20 → free.

3.4 2-Hour Free Session Prune

#!/bin/bash
NOW=$(date +%s) MAX=7200
wg show wg0 dump | tail -n+2 | while read pubkey _ ip _ _ _ handshake _; do
    [ -z "$pubkey" ] && continue
    AGE=$((NOW-handshake))
    if iptables -t mangle -L POSTROUTING -n | grep -q "$ip.*0x20" && [ $AGE -gt $MAX ]; then
        wg set wg0 peer "$pubkey" remove
        iptables -t mangle -D POSTROUTING -s "$ip" -j MARK 2>/dev/null
        echo "pruned free peer $ip (${AGE}s)"
    fi
done

Systemd timer: /etc/systemd/system/mira-prune.timer · OnCalendar *:0/5 (every 5 min).

3.5 Volume Cap Enforcement

Parsed from wg show wg0 transfer every prune cycle. If per-peer received+transmitted exceeds 50 GB for paid tier, remove peer. Accumulate in SQLite peers.db.

7. Abuse Safeguards

7.1 Per-Peer Connection Limits

iptables -I FORWARD -i wg0 -p tcp -m connlimit --connlimit-above 50 --connlimit-mask 32 -j REJECT --reject-with tcp-reset
iptables -I FORWARD -i wg0 -p udp -m connlimit --connlimit-above 200 --connlimit-mask 32 -j DROP

7.2 Registration Rate Cap (Python)

_registry = defaultdict(list)
PEER_WINDOW = 3600; MAX = 5
def rate_check(ip):
    now=time.time(); _registry[ip]=[t for t in _registry[ip] if now-t=MAX: return False
    _registry[ip].append(now); return True

Return 429 Too Many Requests if exceeded.

7.3 Block P2P on Free Tier

iptables -A FORWARD -i wg0 -m mark --mark 0x20 -p tcp -m multiport --dports 6881:6889,6969,1337,51413 -j REJECT --reject-with tcp-reset

7.4 Anti-Spoofing

iptables -A FORWARD -i wg0 -s 10.66.66.0/24 -j ACCEPT
iptables -A FORWARD -i wg0 -j DROP
