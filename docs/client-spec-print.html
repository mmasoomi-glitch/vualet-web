2. Platform TUN Specs

2.1 Windows

  • Ship wireguard-installer.exe as embedded resource
  • Extract to %LOCALAPPDATA%\Mira VPN\WireGuard\
  • Silent install: msiexec /i wireguard.msi /quiet /norestart DO_NOT_LAUNCH=1
  • Drive tunnel via wireguard.exe /installtunnelservice / /activate
  • No user prompts beyond mandatory Windows UAC

2.2 Android

  • Extend VpnService
  • Builder.addRoute("0.0.0.0",0) + .addDisallowedApplication(packageName)
  • foregroundServiceType="specialUse" with PROPERTY_SPECIAL_USE_FGS_SUBTYPE="vpn"
  • No maxSdkVersion cap on FOREGROUND_SERVICE_SPECIAL_USE
  • WireGuard-Go or Xray Reality (see mmasoomi-glitch/uncle-z-calc)

2.3 iOS / macOS

  • NEPacketTunnelProvider + WireGuardKit (Swift Package)
  • App Group: group.com.vualet.mira
  • Bundle ID: com.vualet.mira.PacketTunnel
  • ITSAppUsesNonExemptEncryption = false (standard crypto only)
  • PrivacyInfo.xcprivacy required (UserDefaults CA92.1, FileTimestamp C617.1)

2.4 Linux

  • wg genkey / wg pubkey → POST to API → wg-quick up mira
  • API config output is already wg-quick compatible

7. Key Gotchas

  1. Traffic loop on Android: Builder.addDisallowedApplication(packageName) is mandatory. Without it, VPN app outbound traffic loops through its own tunnel and no packets reach the server. Tested + confirmed.
  2. Foreground Service on Android 14+: specialUse not vpn. No maxSdkVersion cap.
  3. WireGuard key format: 44-char base64, not base64url. No - or _.
  4. iOS Privacy Manifest: PrivacyInfo.xcprivacy mandatory since iOS 17. App Store rejects without it.
  5. iOS encryption declaration: ITSAppUsesNonExemptEncryption = false. WireGuard only uses standard Curve25519 + ChaCha20.
  6. Windows UAC: unavoidable for any kernel TUN driver. NordVPN and Psiphon have the exact same popup.
  7. NowPayments IPN signature: HMAC-SHA512 over raw JSON body, verified constant-time. Header: x-nowpayments-sig.
  8. Rate limiting: /tunnel/issue has no rate limit yet. Add via nginx limit_req_zone at scale.
